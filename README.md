# 🌌 Vanessa's Editor

Um editor Markdown profissional com tema Neon Espacial, desenvolvido para estudos de Álgebra Linear e Geometria.

![Versão](https://img.shields.io/badge/versão-1.0.0-00f3ff)
![Licença](https://img.shields.io/badge/licença-MIT-ff00ff)

## ✨ Funcionalidades

- 📝 **Editor Markdown** com CodeMirror
- 🧮 **Suporte LaTeX** via MathJax (matrizes, integrais, somatórios)
- 📊 **Gráficos Interativos** com Plotly.js (funções matemáticas)
- ⌨️ **Modo Vim** (atalhos `hjkl`, `dd`, `yy`, `p`)
- 🎨 **Dois Temas**: Neon Espacial (escuro) e Clean Light (claro)
- 📂 **Abrir arquivos** locais (.md, .txt) + Drag & Drop
- 💾 **Exportar** para Markdown, HTML e PDF
- 📋 **Copiar** para área de transferência
- ❓ **Guia de atalhos** integrado (F1)
